# Somatosensory Sympathetic Skin Response (SSR) & Sudomotor Autonomic Reflex Skill

This skill computes electrophysiological sympathetic skin response parameters to detect small-fiber autonomic neuropathy and sympathetic dysautonomia.

## Core Capabilities
- Evaluates palmar onset latency (normal: 1.20 - 1.60 s) and peak-to-peak amplitude (>= 1.0 mV).
- Evaluates plantar onset latency (normal: 1.80 - 2.25 s) and peak-to-peak amplitude (>= 0.5 mV).
- Computes the plantar-to-palmar latency delta (normal: 0.50 - 0.80 s) reflecting unmyelinated postganglionic C-fiber conduction along the spinal axis.
- Tracks stimulus habituation across repeated trials.
- Classifies sudomotor polyneuropathy, central sympathetic conduction delay, and hyperarousal states.

## Zero-Mock Architecture
Standard Python standard library only with zero external dependencies.
