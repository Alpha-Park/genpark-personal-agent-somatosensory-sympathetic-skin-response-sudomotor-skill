# Somatosensory Sympathetic Skin Response (SSR) & Sudomotor Autonomic Reflex Skill

A production-grade, zero-mock personal agent skill engineered for electrophysiological sudomotor assessment, unmyelinated sympathetic C-fiber reflex quantification, and autonomic neuropathy profiling.

## Features
- **Palmar & Plantar SSR Latency Analysis**: Exact determination of sympathetic efferent conduction timing.
- **Sudomotor Denervation Screening**: Detects absent, delayed, or attenuated skin potential responses.
- **Habituation Dynamics**: Quantifies sudomotor habituation ratios across serial sensory or acoustic stimuli.
- **Pure Standard Library**: Zero external dependencies; fully portable for edge and clinical AI deployment.
